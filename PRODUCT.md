# Impeccable Design Context (PRODUCT.md)

This file serves as the strict design truth for the AI agent, generated by the Impeccable `/init` methodology. It dictates the visual language, typography, and "anti-slop" rules for the Pakdeepan Kindergarten Website.

## Brand Identity & Vibe
- **Vibe:** Premium, modern, authoritative yet warm, clean and spacious.
- **Audience:** Discerning parents seeking high-quality early childhood education.
- **Visual Principle:** White-dominated surfaces with controlled, elegant color accents. No chaotic colors.

## Color System
- **Backgrounds:** Pure white (`#ffffff`) for cards/surfaces, light sky-blue washes (`#e0f2fe`) for subtle hero backgrounds.
- **Primary Accent:** Light Pink (`#f472b6`) for key buttons, callouts, and icon badges.
- **Secondary Accent:** Sky Blue (`#38bdf8`) for gentle contrast tags.
- **Headings:** Deep Navy (`#1e3a8a`) for maximum readability and prestige.
- **Text:** Dark slate (`#0f172a`) for high contrast body text.

## Typography
- **Headings (`h1`, `h2`, `h3`):** `Outfit` (font-display-lg, font-serif) – Geometric, academic, modern.
- **Body & Interface:** `Plus Jakarta Sans` (font-body-md, font-sans) – Highly legible, clean.
- **Signature Accents:** `Sherlina` (font-sherlina) – Used sparingly for emotional taglines (e.g., "Learn ♡ Grow").

## Strict Impeccable Anti-Slop Rules
1. **Single-Color Iconography Rule:** All feature icons, stat badges, and navigation tiles MUST use a uniform color scheme (e.g., `text-primary bg-primary/10`). Multi-colored rainbow or pastel icon arrays are strictly prohibited.
2. **Architectural Layouts:** Avoid floating "vibecoded" bento boxes with no structure. Use clean, connected docks with hairline dividers (`divide-x divide-slate-100`).
3. **Tactile Feedback:** Interactive elements must feel alive but subtle. Use `active:scale-[0.97]` for buttons and cards.
4. **No Placeholder Routes:** Every navigational tile or link must route to a valid path, zero `#` placeholders.
5. **Glassmorphism:** Use tasteful glassmorphic effects for overlays (e.g., Nav bar with `backdrop-blur-xl bg-white/82`). No excessive or heavy drop shadows.

## Enforcement
This document will act as the master design directive for all frontend component generation and Impeccable audits (`npx impeccable detect`).
